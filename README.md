# barline

MIDI の**打ち込み・ダウンロード・譜面化**ができる、ブラウザ完結型の Web アプリです。

## 機能

- 🎹 **打ち込み** — ピアノロール編集 / 画面上の鍵盤 / ステップ入力
- ▶️ **再生** — Tone.js によるテンポ・拍子同期再生
- ⬇️ **MIDI 書き出し / 読み込み** — 標準 MIDI ファイル（`.mid`）の入出力
- 🎼 **譜面化** — 打ち込んだ音を自動量子化して五線譜で表示（VexFlow）

すべてクライアントサイドで動作し、サーバーは不要です。

## 技術スタック

| 領域 | 採用技術 |
|------|----------|
| フレームワーク | React 19 + TypeScript + Vite |
| 状態管理 | Zustand |
| 音声再生 | Tone.js |
| MIDI 入出力 | @tonejs/midi |
| 譜面描画 | VexFlow 5 |
| Lint / Format | Biome |
| テスト | Vitest |
| デプロイ | GitHub Pages（GitHub Actions） |

## 開発

```bash
pnpm install      # 依存インストール
pnpm dev          # 開発サーバー起動
pnpm test         # ユニットテスト
pnpm lint         # Lint / Format チェック
pnpm typecheck    # 型チェック
pnpm build        # 本番ビルド
```

## データモデル

再生・MIDI 書き出し・譜面化のすべてが単一の `Song`（`src/types/song.ts`）から派生します。
時間はテンポ非依存にするため「拍（四分音符 = 1）」で保持しています。

## 使い方

1. **ステップ入力**パネルで音価（4分・8分など）を選ぶ
2. **鍵盤**をクリック、または**ピアノロール**の空白をクリックしてノートを入力
3. ノートはドラッグで移動、右端ドラッグで長さ変更、選択して Delete で削除
4. **▶ 再生**で試聴
5. **⬇ MIDI 書き出し**で `.mid` をダウンロード
6. 下部の**譜面**に五線譜が自動表示される
